# 风扇变装转场

让前景木色扇叶扫过镜头，在遮挡后依次揭示新的穿搭。固定俯拍人物躺在地毯上，配合暖色窗光、胖猫同色系换装和自然的小互动，制作秋冬穿搭、礼服或个人造型短片。

技能标识：`fan-blade-outfit-transition`。

## 可以做什么

- 输入模特参考与2至5套服装，生成同场景的上身关键帧和风扇变装视频。
- 复用已有上身图，以一张图固定构图、人物位置、猫咪位置和光影，其余图片提供服装参考。
- 为同一只胖猫设计与人物每套穿搭呼应的小背心或马甲，在同一次扇叶遮挡中更换。
- 安排呼吸、眨眼、看猫、浅笑和轻抚等小动作，避免全程僵硬摆拍；也支持不加猫。
- 只输出关键帧，或只写一份完整、精细的视频提示词，不执行生成。

默认9:16竖屏，3套约10秒；4至5套可用15秒。实际时长和素材引用方式依当前生成工具支持的能力调整。

不用于逐件穿衣过程、普通走秀、风扇产品广告或保证尺寸准确的服装试穿。

### 先生成关键帧

上传1张模特参考和3张服装图，明确每张用途，然后调用技能：

> 第1张是模特，第2至4张是三套服装。先生成三张独立的9:16俯拍上身关键帧，保持同一个人、同一躺姿和同一暖灰棕色地毯。旁边加一只奶油色胖猫，每套猫衣与人物服装配色呼应，先不生成视频。

### 用已有关键帧做视频

> 用这三张上身图做10秒风扇变装，按上传顺序换衣服。以第一张固定人物、猫咪和场景，第二、三张提供服装参考。人物自然看猫、微笑，猫咪轻柔回应，人物和猫衣都在扇叶遮挡后更换。

### 只要完整提示词

> 只根据这三张上身图输出一份完整的视频提示词，不生成图片或视频。10秒、9:16，人物和胖猫一起变装，详细写清表情、动作、两次扇叶遮挡与衔接。

可直接参考 [三套穿搭与胖猫的完整提示词](examples/three-outfits-with-cat.md)。示例中的衣服可按自己的素材更换，人物身份以自己提供的参考为准。

## 工具要求与实际边界

- 写提示词只需要能够读取技能和参考素材的Agent。
- 生成关键帧需要可用的图片生成或编辑能力；生成视频需要可用的视频生成能力。安装本技能不会自动提供模型、账号、额度或服务授权。
- 多套衣服的一致性取决于工具实际支持的多图参考、首尾帧或编辑能力。一次生成失败时，可按技能拆成相邻造型的转场段；只有实际具备剪辑能力时才交付拼接成片。
- 原商品图的拉链、纽扣、领口、裤型等需要与结果核对。创意造型图不能直接当成精确商品还原或真实试穿结果。
- 用户只要求提示词或关键帧时，不自动生成视频；公开发布和提交活动表单也不属于技能的自动动作。
